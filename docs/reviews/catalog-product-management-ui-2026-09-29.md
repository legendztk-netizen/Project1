# 产品管理页面交互优化（2026-09-29）

范围：`/admin/catalog/products`，按用户选择的综合管理视角展示规格、价格、发布状态和数据缺项。

## 行为

- 搜索支持 SKU、系列编号/名称及规格文本，不区分大小写；类目多选、发布状态、待处理筛选立即生效。URL 保存条件，返回恢复；改变条件回到第一页。
- 顶部统计基于全部匹配结果，分页仍按系列分组。按 SKU 匹配时保留父系列上下文，并显示匹配/全部数量。搜索和状态筛选自动展开匹配子体。
- 系列显示 SKU 数、按币种分别计算的零售价格范围、上线 SKU 数、未定价、草稿修订、技术资料 Pending、总成待更新。SKU 显示尺寸/压力/接口、零售价格和销售单位；Inherited 不算技术资料缺失。
- 新增入口改为类目和系列/SKU 选择弹窗，系列行可以直接新增子体并预填系列。保留原发布命令、权限、未保存关闭确认和删除影响检查；新增加载、保存反馈。
- 选中后显示批量操作区，父子选择独立，混合选择限制保持不变。支持一键展开/收起，窄屏表格横向滚动。

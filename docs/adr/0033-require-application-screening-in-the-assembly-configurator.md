# Offer Optional Operating-Condition Screening in the Assembly Configurator

Installed Protection remains part of the guided assembly flow. Fluid medium,
maximum system working pressure, and operating-temperature range are optional
operating context, shown in a collapsed section marked `Optional`. Omitting the
section does not block saving the protection selection or proceeding to review;
the quote reviewer may confirm missing context with the customer.

When the customer opens the section, all operating-condition fields must be
completed together. Stated values outside catalogue reference ranges move to
manual quotation, while unknown or nonstandard inputs remain quotable with
Technical Review Required. Application-specific protection rules can be applied
automatically only when the relevant operating context is supplied. The website
does not turn component compatibility or optional screening into an automated
suitability certification.

# Allow Reference Combinations in the RFQ Configurator

The launch configurator may present exact hose, hose-end, and ferrule
relationships supported by market-reference data as RFQ-Eligible Combinations,
because configuration is the storefront's primary customer value and no payment
occurs online. Catalog Publication Status, RFQ Eligibility, and Qualification
Status remain independent: a Published and Eligible relationship may still be
Not Tested and must never be described as qualified. A submitted configuration
is not a production commitment: the seller must confirm a Production-Approved
Combination or offer a substitute before issuing the PI.

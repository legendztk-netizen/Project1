# Limit Hose Series Reference Content to Sourced Facts

User decision, 2026-10-27. Applies to the size chart and guide shown below the
order panel on a Hose Series product page, starting with 601R1.

The block exists to help customers choose a size, not to add text for search
engines. Every statement must trace to the Catalog Master Data in D1, which came
from the factory catalogue, or to the factory catalogue itself, such as the -8
inside-diameter range on its 601R1 page. Statements drawn only from general
industry knowledge or from standards we do not hold, such as advice on choosing
a bore by flow or comparisons with SAE J517 minimum pressures, are left out
until a document we hold supports them.

The size chart reads every number from the published catalogue and shows each
value as stored. A value that looks wrong is corrected in the catalogue, never
overridden in the storefront. The chart shows the Hose Metric Size and labels it
as such, never as a measured bore. It leaves out the reference price, processing
time and SKU, which the order panel already shows. Its Online Assembly column is
the Configurator-supported Size set: the hose SKUs with at least one Hose End
compatibility in the active catalogue, the same cached list Build a Hose offers.
When that list cannot be read, the column and the related question are left out
rather than guessed.

A hand-written block per series was kept for 601R1 because its text was
reviewed against the sources above. Extending it to other series requires the
same review, with any numbers in the text taken from catalogue rows.

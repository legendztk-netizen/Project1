# Build Hose Assemblies in China

For the initial retail launch, all made-to-order Hose Assemblies will be
produced and inspected at the existing China Assembly Facility, then shipped
cross-border. This avoids the fixed cost and operational complexity of a US
crimping workshop or local production partner; the storefront must instead
accommodate longer assembly lead times, international freight, split
fulfillment, and more restrictive return handling.

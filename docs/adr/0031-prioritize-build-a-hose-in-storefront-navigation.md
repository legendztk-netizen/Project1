# Prioritize Build a Hose in Storefront Navigation

The storefront's primary product navigation is Build a Hose, Hydraulic Hose,
Hose Fittings, Adapters, and Quick Couplings. The first viewport provides
product search and direct configurator access rather than a marketing-only
landing page.

ADR 0056 (2026-10-14) removed the former Crimp Ferrules subcategory of Hose
Fittings: all crimp fittings are one-piece.

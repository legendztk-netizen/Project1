# Use Reviewed AI-Generated Hose End Shape Images

The 200 launch Hose End SKUs use 16 original AI-generated representative shape
images rather than one photograph per SKU or two real photographs per visual
construction group. Each image is mapped by Interface Family, gender, swivel or
fixed construction, angle, and sealing form, and must pass a structural review
before publication. The website labels the image `Representative image -
dimensions vary by size` and keeps interface, thread, hose size, and exact SKU
as authoritative text; competitor images remain reference-only and are not
republished.

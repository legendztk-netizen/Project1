# Use Versioned Measurement Diagrams with Code Overlays

Length Measurement Methods use original brand-neutral illustrated base assets,
including reviewed AI-generated artwork, while deterministic website overlays
place all technical endpoints, arrows, centerlines, labels, and values. Each PI
snapshots the method and diagram version, and missing Hose End mappings move to
manual quotation rather than relying on an unverified image or an unavailable
cut-length calculation.

# Use Admin Discretion for Approved Assembly Cancellation

Production Approval makes a Hose Assembly specification immutable and removes
customer self-service cancellation, but the application does not automatically
decide cancellation eligibility from cutting, crimping, assembly, or completion
milestones. After customer-support contact, an authorized admin uses current
factory information to approve or decline an exceptional cancellation; approval
creates a Cancellation Resolution, while a replacement configuration is always
purchased through a new Follow-on Quote.

## What to build

将五类产品集中到“管理所有产品”，管理员可以按系列/子体浏览、选择、编辑、新增和条件删除，并从手动表单直接发布。将 SKU 参数、原币种价格、适用包装和图片合并提交；保留系列销售规则的清晰入口，使客户能看到新价格、按原币种形成询价，并保持历史内容不变。

## Acceptance criteria

- [x] “产品数据维护”包含“管理所有产品、销售、包装和价格、总成管理”三个入口，批量导入并入“产品审核与发布”（2026-09-09 用户确认）；本票迁移旧手动新增/编辑能力，不在新入口继续写共享 Draft。
- [x] 产品小类支持胶管、压接接头、套筒、过渡接头、快速接头多选，未选即全部；SKU 支持模糊查询。有系列按系列一级折叠，无系列按 SKU 一级显示。
- [x] 默认每页 20 个一级项目，可选 50；展开子体不计入分页条数；筛选或翻页清空选择。列表展示系列图片、SKU、关键尺寸、当前价格币种与更多。
- [x] 系列复选框不级联选中子体；单系列/单 SKU 可编辑，多 SKU 仅批量删除，多系列或系列/SKU 混选禁用编辑及系列删除。“更多”直接打开编辑弹窗，查看权限用户只读。
- [x] 新增菜单支持悬停、点击、键盘聚焦；胶管/压接接头提供新增系列和子体，其余三类沿用单产品表单。参数表单中英文，导航与普通操作中文；只在提交时保存，关闭未保存修改提示放弃。
- [x] 合法系列可直接发布，不要求 SKU 价格；系列编号不可改，代表图可继承/覆盖。新子体在同一表单提交参数、自动生成 Sales SKU、零售价格/币种、适用包装和图片，经 Ticket 01 命令应用上线/草稿/停用状态。
- [x] 包装长度按类型和销售方式校验：预包装定长胶管必须为正；按客户长度裁切的胶管可空、填入必须为正，不能取代客户长度；接头、套筒、过渡接头、快速接头不要求且拒绝不适用的新值。其余包装字段保持选填，前后端规则一致。
- [x] 每个 SKU 修订保存一组金额和受支持币种，默认 USD，至少验证 USD、CNY、EUR；更换币种须提交对应金额，不自动转换，不增加同 SKU 多币种并行价目表。金额格式、精度、展示和排序保留币种含义。
- [x] 系列销售规则固定在“产品数据维护 → 销售、包装和价格”，按产品类目和系列维护销售单位、MOQ、交期、原产地、HS Code、数量输入和长度规则。直接发布系列修订，影响继承子体但不覆盖其价格、币种、包装或覆盖图。
- [x] 原商业维护入口编辑 SKU 价格/包装也接入统一条目发布；缺少上线必需的系列规则时给出该入口并阻止不完整 SKU 上线，不产生隐式价格或规则。
- [x] 产品详情和询价行显示原金额/币种，同币种汇总，异币种分组；筛选和排序不跨币种比较裸金额。价格、币种和商业规则变更用于新询价，历史保持原值。
- [x] 总成部件、装配服务和保护费用只有全部币种一致时自动估价；混币时保留有效配置及原币种来源，显示人工核价并可提出人工询价，不产生零价、伪造总价或自动换汇。
- [x] USD 门槛与 DDP/DAP 自动路由仅在完整相关小计可确定为 USD 时判断；其他情况进入人工商业确认，不把未知汇率条件默认为达标或不达标。保持现有纯 USD 路径，不扩展正式 PI/支付结算。
- [x] 已上线 SKU 的删除执行停用并从普通列表隐藏，历史仍可解析；从未上线且无保留引用者才可物理删除。批量删除明确展示数量及实际结果。
- [x] 存在上线子体或其他有效引用时禁止删除系列并显示阻止数量；仅草稿子体可连同未发布请求处理，须展示依赖影响且不留悬空引用；仅停用子体采用隐藏/墓碑，保留历史。保留来源与删除审计。
- [x] Dash 匹配及既有系列/套筒/剥胶、生命周期变化调用 Ticket 01 的即时失效门禁。压力、温度、扣除量不新增总成更新或额外校验；价格、币种、包装、图片、销售规则修改无需重建。

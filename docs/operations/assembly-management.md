# 条目级总成管理（Spec 11 / #85）

入口 `/admin/catalog/assemblies`。本地条目模式使用新管理页；尚未切换的数据库继续进入旧参考数据页。正式激活与共享 Draft 迁移仍由 Ticket 05 负责。

## 管理与更新

组合身份为有顺序的 `[胶管 SKU, A 接头 SKU, A 套筒 SKU, B 接头 SKU, B 套筒 SKU]`。A/B 不同部件反转是另一身份。管理页默认覆盖全部组合，按完整数据集筛选，每页 50 条，无表头全选。

手动保存可将自动组合固定为手动来源，已有手动身份拒绝重复。手动关系及停用排除跨生成保留；保留不代表当前可用。启用要求部件有效、系列就绪。停用和启用原因、操作者、时间、请求标识及 IP 均保留在不可变操作和管理员审计中。

更新先预览系统完整待更新系列，提交时重新读取完整范围；不使用列表选中范围。逐系列原子追加不可变端点依据、产品修订与兼容输入版本，然后推进该系列生成指针及就绪状态。A/B 组合由本次固定端点依据确定性展开，避免将平方增长的组合 JSON 塞进单个 D1 字段。旧生成记录、手动关系及排除操作保留。

产品发布使用新旧 Dash、系列、套筒、剥胶、生命周期依赖失效系列；新匹配可能性与既有组合引用都纳入。生成提交校验产品失效序号和关系输入版本；相关输入再次变动会失败，不能清掉新的待更新。价格、币种、图片、压力、温度和扣除量不会单独触发重建。失败系列留在待更新列表，其他成功系列正常提交。

## 工作表 04 来源

沿用 `catalog_pending_relation_sources` 的 `{sheet,row,values,cells}` 原始数据契约，迁移来源也应写入此表并保留批次溯源。应用校验完整字段及当前在线产品，保留单端三件套与压接参数，不补写不存在的另一端，也不将导入的资格标签转换为生产批准。两端只从现有可询价端点集合组合。

未处理来源不修改已有配置数据；尚无已发布依据的新三件套不会通过自动规则提前使用。来源应用、拒绝或删除后，需要更新对应系列；原始内容不删除，处置与依据留痕。

## 客户和历史

候选端点、完整组合校验、Quote List 原子写入与 RFQ 提交都读取同一可用组合视图。直接调用接口不能绕过停用、待更新或失效部件。已保存配置恢复仍重新准备和校验；已有 RFQ、报价与图片快照不改写。

估价继续读取当前 SKU 原币种报价及 USD 服务费用。全部 USD 输入可以估价；存在非 USD 输入与 USD 服务费混合时转人工，不换汇。快照保留原币种产品报价，客户无币种选择器。

# Issue Tracker

Project work is tracked in GitHub Issues for
`legendztk-netizen/Project1`.

- Repository: `https://github.com/legendztk-netizen/Project1`
- CLI: use the authenticated `gh` command.
- Pull requests are not an issue intake surface.
- Specs are published as GitHub Issues and labelled `ready-for-agent` only when
  they are bounded enough to be converted into implementation tickets.
- A project-level PRD or roadmap is reference material and must not receive the
  `ready-for-agent` label.
